## 🚀 Установка

1. Скачайте [`ComelyLauncher-Setup.exe`](https://github.com/xxxxwero/ComelyLauncher/releases/latest/download/ComelyLauncher-Setup.exe).
2. Запустите его, выберите папку и нажмите **«Установить»**. Права администратора не нужны.

Нужна 64-битная Windows 10 или 11. По умолчанию лаунчер ставится в `%LOCALAPPDATA%\Programs\ComelyLauncher` и создаёт ярлыки на рабочем столе и в меню «Пуск».

Удалить лаунчер можно в «Приложениях и возможностях» Windows. Сборки, миры и файлы игры при этом останутся на месте.

> [!NOTE]
> **Windows может показать предупреждение SmartScreen.** Файл не подписан платным сертификатом, поэтому система не знает издателя. Чтобы продолжить, нажмите «Подробнее», затем «Выполнить в любом случае». Если сомневаетесь, сначала прочитайте следующий раздел.

## 🔒 Безопасность и данные

Код открыт, чтобы это можно было проверить самому.

- **Проверка файла:** загрузите установщик на [VirusTotal](https://www.virustotal.com/) или соберите лаунчер из этого кода, инструкция ниже.
- **Аккаунты:** токены входа хранятся на вашем компьютере в зашифрованном виде (Windows DPAPI) и никуда, кроме сервисов входа, не отправляются.
- **Что получает разработчик:** только то, что вы сами отправили через раздел «Поддержка», и служебные данные обращения: ник, версии лаунчера, Windows и игры, загрузчик, число модов, объём памяти и причину вылета. Логи прикладываются, если оставить галочку. Токены входа и путь к папке пользователя из них убираются, но проверяйте, что отправляете. Логи хранятся 90 дней.
- **Вход в поддержку:** аккаунт Microsoft подтверждается подписью сертификата игрока Mojang, токен входа на сервер не передаётся. Код сервера лежит в [`support-server`](support-server).

<details>
<summary><b>Куда лаунчер обращается</b></summary>
<br />

| Сервис | Зачем |
| --- | --- |
| Mojang и Microsoft | вход, файлы игры, новости |
| Ely.by | только если вы входите через него |
| Modrinth | поиск и установка контента |
| GitHub | проверка обновлений |
| Сервер поддержки на Cloudflare | новости разработчика, а если вы писали в поддержку, ещё и проверка новых ответов |

</details>

## 🛠 Сборка из кода

Нужны Node.js 22 или новее и Windows с .NET Framework 4, он уже есть в Windows 10 и 11.

```bash
npm install
npm run dev
```

Собрать установщик `release/ComelyLauncher-Setup.exe`:

```bash
npm run dist
```

> [!IMPORTANT]
> Графики автора в репозитории нет. При сборке вместо неё создаются однотонные картинки, поэтому лаунчер работает полностью, но выглядит проще официального. Официальный установщик отличается от такой сборки своей графикой.

Устройство проекта описано в [ARCHITECTURE.md](ARCHITECTURE.md), правила разработки и выпуск версий в [AGENTS.md](AGENTS.md).

## 🤝 Как создан проект

ComelyLauncher разработан человеком вместе с ИИ-агентом: идеи, требования, решения и проверка на реальной игре за человеком, некоторая часть кода написана с помощью ИИ. Поэтому код открыт для проверки, а о найденных ошибках можно сообщить в разделе [Issues](https://github.com/xxxxwero/ComelyLauncher/issues) или через «Поддержку» в лаунчере.
